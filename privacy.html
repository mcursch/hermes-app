Privacy policy

Hermes is a personal-use application operated by and for a single individual, the owner of the Google account it connects to.

Data accessed

With the owner's authorization, Hermes accesses the owner's Google account data (for example Gmail, Calendar and Drive) solely to generate summaries and perform tasks for the owner.

Use and sharing

Data is used only to provide these features to the owner. It is not sold, shared with third parties, or used for advertising. Google user data is handled in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Storage and deletion

Data is processed on the owner's private server. Access can be revoked at any time at myaccount.google.com/permissions.
